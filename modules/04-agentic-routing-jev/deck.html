The application's decision

A clear intent may still need clarification.

“Can I return one of the other blue items too?” expresses return intent, but the order contains two other blue items.

Design rule

Confidence thresholds are demo policies. They are not calibrated probabilities of correctness; test them on reviewed conversations.

The authored support journey

History changes what the next turn means.

TurnCustomer saysRaw → final routeWhy
01Where are my Studio headphones?order→orderDelivery question
02They arrived damaged. Can I return them?returns→returnsHistory resolves “they”
03Can I return one of the other blue items too?returns→clarifyTwo blue items remain
04I mean the Sport Earbuds.returns→returnsFollow-up names one item

This is the intended scenario, not a promise that every live model call takes the same path. A low-confidence route can safely become clarify on any turn.
