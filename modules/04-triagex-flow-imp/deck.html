03 / 08

under the hood · crewai cognitive memory

Memory is cognition, not storage

encode

Every memory gets a scope (a place in the tree), categories, and an importance (0–1). Structure emerges — no schema up front.

consolidate

New facts are checked against existing ones. Contradictions update old records instead of piling up beside them.

recall

Composite scoring — similarity + recency + importance — so what matters outranks what merely matches. Uncertain recalls dig deeper and report evidence_gaps.

extract

extract_memories() splits raw text into atomic, self-contained facts — each consolidated independently.

forget

Active, on purpose: temporal decay (e.g. older than 30 days) keeps stale facts from poisoning new runs.

it's flows all the way down

Encode and recall are themselves CrewAI Flows — each operation is a reasoning process, not a read or write.

recall score ❯ similarity × w + recency × w + importance × w · crewai.com/blog — cognitive memory for agentic systems

06 / 08

why this stays safe

Memory proposes. Humans dispose.

  • Strict majority required — a tie or an empty recall proposes nothing.
  • Default is reject — an unmappable reviewer reply holds everything.
  • Double-gated publish — Linear needs the human's approval AND the explicit sync opt-in.
  • Holds are learning too — not_urgent verdicts stop the same false proposal from returning.
  • Degrades gracefully — no embeddings key? recall/remember are skipped and the flow runs on labels alone.

Spend human judgment once — then reuse it. Never let memory skip the human.
