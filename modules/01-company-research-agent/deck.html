class CompanyResearchFlow(Flow):
    @start()
    def research(self):
        agent = Agent(
            role="TODO: ...",
            goal="TODO: ...",
            backstory="TODO: ...",
            mcps=[build_firecrawl_mcp(
                allowed_tools=["firecrawl_search"]
            )],
        )
        result = agent.kickoff(
            "Research CrewAI ...",
            response_format=CompanyResearchBrief,
        )
        return result.pydantic or result.raw

The output contract

A plausible paragraph is not the checkpoint.

Request CompanyResearchBrief and inspect its evidence. The schema shapes the response; cited URLs and open questions make it reviewable.
