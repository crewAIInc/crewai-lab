Lab close

Know who decides the next step.

Each module adds one control: a bounded Agent, explicit Flow state, per-turn authorization, then a typed router with an abstention path.

Bound the capability

Give an Agent a clear job and only the tools it needs.

Make the route explicit

Keep state, permissions, and review gates in the application.

Keep the evidence

Record model answers, overrides, handlers, and outcomes.

A reliable run is one you can explain turn by turn.
